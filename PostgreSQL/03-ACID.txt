Lab setup

- Install vmware wordstation (Next - Next - Finish)
- Download lab01.zip to D:/drive (pref - separate folder)
- Extract lab01.zip to have lab01 folder, remove .lck folder from lab01.
- Right click on .vmx file and open with vmware workstation

Clone the virtual machine?

- copy lab01 to lab02
- open vmx file with notepad and change display name {displayName = "lab02"} and save
- open vmx file with vmware workstation
- Select "I copied it" when asked
- To change machine name - "hostnamectl set-hostname lab02"
