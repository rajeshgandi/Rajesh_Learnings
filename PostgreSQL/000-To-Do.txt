Fill Factor: 
What is Fill Factor?
Definition: An integer value from 10 to 100 (default is 100).
Function: A fill factor of 80 means PostgreSQL fills a data page up to 80% and leaves 20% empty for incoming updates and insertions

-- HOT Updates

Quick Rules of Thumb
Default (100): Best for read-only or append-only tables where rows are rarely updated.
Lowered (70-80): Recommended for tables with frequent updates to enable HOT updates and reduce table bloat.
Configuration Example: ALTER TABLE table_name SET (fillfactor = 80);

auto_explain.log_min_duration = 250

auto_explain.log_min_duration-1	The execution threshold in milliseconds. Set to 0 or higher to activate.
auto_explain.log_analyzeoff	When turned on, logs actual execution times and loops (equivalent to running EXPLAIN ANALYZE).
auto_explain.log_buffersoff	Includes buffer/memory usage statistics in the logs (requires log_analyze to be on).
auto_explain.log_timingon	Controls whether row-timing overhead is tracked. Turning this off slightly reduces overhead when log_analyze is active.
auto_explain.log_nested_statementsoff	When turned on, logs queries executed inside stored procedures or PL/pgSQL functions.
auto_explain.log_parameter_max_length-1	Controls the length of query parameter logs. -1 logs full parameters, 0 hides them, and >0 truncates them to that size in bytes.
