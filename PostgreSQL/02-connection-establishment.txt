connection establishment

- /usr/pgsql-14/bin/postgres -D /u01/pgsql/14    (postmaster process)

	- connection establishment					--> listener
	- Take care of other background processes	--> PMON
	- Instance recovery.						--> SMON
	
log_connections = on
log_discconnections = on
log_duration = on
listen_address=*

systemctl stop firewalld

Everytime a new connection is established., a new backend process pid is created

CLient process request a connection establishment to postaster process.
Postmaster process immediately creates User Backend Process
After Authentication is made, this user backend process connect to the database and is assigned to the client process.

client --> received by --> Postmaster --> creates user backend process --> hba auth.

pg_cancel_backend('<PID>');
postgres=# select *, pg_sleep(30) from emp;
ERROR:  canceling statement due to user request


pg_terminate_backend('<PID>');
