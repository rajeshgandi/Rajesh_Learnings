After first vacuum:

VM : Visibility Map : tracks which one is dead tuple, which one is dead tuple.
FSM: Free Space Map : tracks which position of free space is available in the existing datafile for the new insert/update.

For example., there are 10 blocks 1 to 10., of which only 5,6,7 are dead tuples...
then VM --> SELECT query will goes to VM and scans for 1 to 4 and 8 to 10. . 
FSM ---> scans for 5 to 7 blocks attached to it.

VM contains only boolean data... 1 is live tuple, 0 is dead tuple
pg_visibility extension help to see the content of VM and FSM
